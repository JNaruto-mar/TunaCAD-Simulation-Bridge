# CalculiX isolation and licensing note

CalculiX is an external, user-installed program and is not copied, modified,
linked, bundled or redistributed by TunaCAD. The adapter communicates with the
separate executable through a generated input deck and result files on the
user's machine.

CalculiX's own licensing terms remain the responsibility of its distributor and
user. This repository contains only TunaCAD's provider adapter code. This note
is architectural documentation, not legal advice.
