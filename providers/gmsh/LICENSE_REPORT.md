# Gmsh isolation and licensing note

Gmsh is an external, user-installed program and is not copied, modified,
linked, bundled or redistributed by TunaCAD. The adapter communicates with the
separate executable through files and a child process on the user's machine.

Gmsh's own licensing terms remain the responsibility of the Gmsh distributor
and user. This repository contains only TunaCAD's provider adapter code. This
note is architectural documentation, not legal advice.
